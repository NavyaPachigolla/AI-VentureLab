# AI VentureLab

Multi-Agent AI Startup Research, Validation & Product Planning Platform.

## Technology Stack

- **Next.js** 16 (App Router)
- **React** 19
- **TypeScript** 5
- **Tailwind CSS** 4
- **shadcn/ui** (base-nova)

## Current Phase

**Phase 1 — Foundation** — project structure, design tokens, and reusable UI primitives.

## Local Development

From the `frontend` directory:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
